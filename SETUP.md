## Replace the previous version on Manjaro

If your repository is already cloned at `~/Code/Jatinn07`:

```bash
cd ~/Code/Jatinn07

# Remove assets and the contribution workflow from the previous design.
rm -rf assets
rm -f .github/workflows/snake.yml

# Install the new README and its only required image.
unzip -o ~/Downloads/Jatinn07.zip

# Remove now-empty workflow folders, if possible.
rmdir .github/workflows .github 2>/dev/null || true

git status
git add -A
git commit -m "Refine GitHub profile design"
git push origin "$(git branch --show-current)"
```

If the ZIP is not in `~/Downloads`, replace that path with its actual location.

If the repository is not cloned yet:

```bash
cd ~/Code
git clone git@github.com:Jatinn07/Jatinn07.git
cd Jatinn07
unzip -o ~/Downloads/Jatinn07.zip
git add -A
git commit -m "Add GitHub profile README"
git push -u origin main
```

## GitHub background / theme

A README cannot change the background of GitHub's surrounding profile page. It can only style its own content and embedded images.

To change your own GitHub interface:
1. Open https://github.com/settings/appearance
2. Under **Theme mode**, choose **Single theme**.
3. Select **Dark** or **Dark dimmed**.

This affects your account's GitHub interface. Other visitors see their own theme preference.
